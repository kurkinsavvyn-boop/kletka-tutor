# Вход через VK ID, Яндекс ID, Google и Apple

Вход по почте и паролю уже работает. Кнопки VK, Яндекса, Google и Apple появятся на экране входа сами,
как только вход будет подключён на сервере. Для каждого сервиса нужно один раз создать «приложение»
в вашем аккаунте этого сервиса и получить два значения: **Client ID** и **Client secret**.

Адрес возврата (Redirect URI), который везде спрашивают:

```
https://153-76-170-187.sslip.io/api/oauth2-redirect
```

Когда купите свой домен, адрес поменяется, и его нужно будет обновить в каждом приложении.

## Яндекс ID (начать с него: проще всего)
1. Откройте https://oauth.yandex.ru и нажмите «Создать приложение».
2. Название: «Клетка». Платформа: «Веб-сервисы».
3. Redirect URI: адрес возврата выше.
4. Доступы: «Доступ к адресу электронной почты» и «Доступ к логину, имени и фамилии».
5. Сохраните. На странице приложения будут **ClientID** и **Client secret**.

## VK ID
1. Откройте https://id.vk.com/about/business/go и создайте приложение типа «Веб».
2. Доверенный Redirect URL: адрес возврата выше. Базовый домен: `153-76-170-187.sslip.io`.
3. В настройках приложения возьмите **ID приложения** (это Client ID) и **Защищённый ключ** (Client secret).
4. В разделе доступов включите почту.

## Google
1. Откройте https://console.cloud.google.com, создайте проект «Клетка».
2. «APIs & Services» → «OAuth consent screen»: тип External, название «Клетка», ваша почта.
3. «Credentials» → «Create credentials» → «OAuth client ID» → тип «Web application».
4. «Authorized redirect URIs»: адрес возврата выше.
5. Получите **Client ID** и **Client secret**.

## Apple
Нужна платная подписка Apple Developer (99 $ в год). Имеет смысл подключать вместе с приложением
для iPhone: App Store требует вход через Apple, если в приложении есть вход через VK, Яндекс или Google.

## Как подключить на сервере
Вариант 1 — сами:
1. Откройте админку https://153-76-170-187.sslip.io/_/ (логин и пароль — в файле `server-admin.txt` в папке «Клетка»).
2. Collections → `users` → значок настроек → вкладка «Options» → «OAuth2» → «Add provider».
3. Выберите сервис, вставьте Client ID и Client secret, сохраните.

Вариант 2 — через меня: запишите значения в файл `oauth.txt` в папке «Клетка» (не в чат) и скажите мне,
я подключу и проверю.
