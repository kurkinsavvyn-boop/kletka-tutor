# Промпты для картинок оформления (ChatGPT)

На каждый мультфильм нужно 3 картинки:

| № | Куда | Формат |
|---|---|---|
| 1 | «Сказка», сцена сверху слева | 4:3, горизонтальная, с фоном |
| 2 | «Сказка», сцена снизу справа | 1:1, квадрат, с фоном; на листе обрезается в круг |
| 3 | «Яркий», персонаж в шапке | 1:1, только персонаж, прозрачный фон |

Как работать:
1. Новый чат, в нём один мультфильм.
2. Приложите 1–3 кадра-образца из мультфильма.
3. Отправьте **общий стиль** и **промпт картинки №1**. Потом в том же чате №2 и №3: так стиль совпадёт.
4. Одна картинка за запрос. Если не понравилось: «Ещё вариант, тот же стиль».
5. Скачайте PNG. Для №3 проверьте, что фон прозрачный (в превью видна шахматка).

Если ChatGPT отказывается рисовать персонажа по имени, уберите имя и опишите внешность: «бурый круглый медвежонок с большим чёрным носом» и так далее. Образец на картинке он всё равно учтёт.

## Общий стиль (вставлять первым)

```
Нарисуй детскую иллюстрацию по приложенным кадрам из советского мультфильма.
Не копируй кадр точь-в-точь: перерисуй сцену заново, мультяшнее и мягче,
но так, чтобы персонажи сразу узнавались (силуэт, цвета, одежда, главные черты).

Стиль для всех картинок серии:
- рисованная 2D-анимация, как в советских мультфильмах 1970-х, но чище и ярче;
- ровные заливки цветом, мягкие тени без резких бликов, тонкий тёмный контур;
- добрые лица, живые позы, понятная мимика;
- светлая тёплая палитра, хорошо печатается на обычном принтере;
- никакого текста, букв, цифр, подписей и логотипов на картинке;
- без рамки, без водяных знаков.
Подтверди, что понял стиль, и жди задание на первую картинку.
```

## Картинка №1: «Сказка», сверху слева

```
Картинка №1. Сцена: [ОПИСАНИЕ СЦЕНЫ СВЕРХУ].
Формат 4:3, горизонтальный, 1536×1152.
Сцена с фоном, но фон простой и светлый, без мелких деталей.
Главные персонажи крупно, занимают центр и левую половину кадра,
по краям оставь немного спокойного фона: картинку вставят в рамку со скруглёнными углами.
```

## Картинка №2: «Сказка», снизу справа

```
Картинка №2, тот же стиль. Сцена: [ОПИСАНИЕ СЦЕНЫ СНИЗУ].
Формат 1:1, квадрат, 1024×1024.
Картинку обрежут в круг: всё важное держи в центральном круге,
углы оставь под простым фоном. Фон светлый, однотонный или почти однотонный.
```

## Картинка №3: «Яркий», только персонаж

```
Картинка №3, тот же стиль. Только персонаж: [КТО], во весь рост, [ПОЗА].
Формат 1:1, 1024×1024, PNG с прозрачным фоном.
Никакого фона, пола, теней на земле и предметов вокруг.
Персонаж по центру, с небольшим отступом от краёв, контур чистый.
```
