# Ревью кода и безопасности, 05.11.2026

Проверено после новых возможностей комнаты: звонок по уроку, показ экрана, окна рядом, картинки на листе, PDF по страницам, тема, реакции.

Как проверял:
- читал новый код целиком;
- прогнал в двух окнах браузера (репетитор и ученик) весь урок: звонок, перезагрузки, PDF, картинки, показ экрана, окна рядом, реакции, удаление материала;
- прогнал генератор листов: 213 тем, все уровни, 2 варианта, 5 оформлений, 5870 листов, без ошибок и без NaN и undefined в тексте;
- сверил боевые правила и настройки сервера (только чтение).

## Безопасность

### Исправлено в этот раз

1. **Политика безопасности страницы (CSP).** Раньше её не было. Теперь страница не подключает чужие скрипты, чужие адреса для данных и чужие фреймы. Разрешены только наш сервер, шрифты Google и библиотека базы с jsDelivr. Все сценарии урока прошли с включённой политикой без единого нарушения.
2. **Реакции собеседника.** Принимаются только шесть наших значков. Раньше принималась любая строка.
3. **Данные материала, которые приходят ученику:** число страниц PDF ограничено 500, пропорции, высота окна, положение и размер картинок приводятся к безопасным числам, фон доски берётся из списка. Всё это пишет репетитор, но ученик такие данные открывает у себя.
4. **Файлы комнаты.** Если материал убрать, его файлы теперь удаляются с сервера. Раньше они копились, а в комнате не может быть больше 999 файлов, и страницы PDF занимают по файлу.

### Подтверждено

- Правила доступа на боевом сервере совпадают с теми, что были проверены: репетитор не может сменить ученика, ученик не может менять название работы, пульс защищён.
- Лимиты запросов включены, сервер за доверенным прокси, пакетные запросы выключены.
- Показ экрана начинается только после выбора в окне браузера. Ученик только смотрит. Кнопка есть только у репетитора.
- Данные, которые ученик присылает репетитору (ответы, результаты, пульс), по-прежнему проверяются и выводятся через `esc` или `textContent`.

### Что остаётся

1. **Средняя. Свободная регистрация репетитора плюс загрузка файлов.** Зарегистрироваться репетитором может любой (`users`: создание без условий). Каждый репетитор может создавать учеников, у каждого ученика своя комната, а в комнату можно загружать до 999 файлов по 25 МБ. Так можно заполнить диск сервера. Варианты: приглашение по коду, подтверждение почты, общий предел места на репетитора. Нужно ваше решение.
2. **Низкая. Лимит файлов в комнате.** 999 файлов на комнату. Для одной комнаты с несколькими учебниками этого может не хватить. Можно поднять до 3000 одной правкой схемы на сервере, нужно ваше согласие.
3. **Низкая. Ручка у ученика проверяется только в интерфейсе.** Через прямой запрос к серверу ученик может нарисовать линию и без разрешения. Он портит только свой лист, репетитор может стереть.
4. **Средняя. Админка сервера** по-прежнему защищена только паролем (без второго шага входа).
5. **Низкая. Опрос** остаётся открытым для записи, пока репетитор не ответит.
6. **Из прошлого ревью без изменений:** синхронизация при работе с двух устройств (последняя запись перекрывает), рост списка попыток.

## Код

### Исправлено

- Наблюдатели за страницами и PDF копились при каждой перерисовке. Теперь снимаются.
- Временные адреса картинок и открытые документы PDF не освобождались при выходе из комнаты. Теперь освобождаются.
- Если в комнате не хватает места для новых страниц PDF, показывается понятное сообщение до начала загрузки.

### Известные ограничения

- В PDF берутся первые 300 страниц.
- Звук вкладки при показе экрана ученику не передаётся.
- Если репетитор перезагрузит страницу до конца отправки PDF, оставшиеся страницы не отправятся, придётся добавить файл заново.
- Ученик видит новое положение окна или картинки после того, как репетитор её отпустил, а не пока тянет.
- Весь код по-прежнему в одном большом файле, автоматических тестов нет. Проверка листов и сценариев урока делается вручную по описанному выше порядку.
