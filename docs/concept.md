# Концепция: генератор заданий для репетитора

## Главная мысль

У А4Умки центр — **генератор**: родитель ищет его в каталоге из 180 штук и сам крутит параметры.
У репетитора центр — **ученик и его программа**. Репетитор думает так: «Маша, 3 класс, русский, сейчас проходим безударные гласные». Значит, путь должен быть именно таким:

```
Ученик → Предмет → Тема → [готовое задание] → Печать или Ссылка → Результат
```

Генераторы никуда не делись, но репетитор их почти не видит: **каждая тема программы уже знает, какие генераторы к ней подходят и с какими настройками**.

## Три уровня структуры

```
Предмет        Математика · Русский · Английский · Окружающий мир · Литературное чтение
  └ Класс      1 · 2 · 3 · 4 (потом 5–9)
      └ Раздел     «Числа до 100», «Орфография», …
          └ Тема       «Сложение с переходом через десяток»
              └ Задания  3–6 готовых пресетов генераторов, разложенных по уровням
```

- **Тема** — главный объект. Она содержит пресеты: «Примеры, диапазон 10–20, переход через десяток», «Окошки 8 + □ = 15», «Лабиринт с примерами», «Текстовые задачи в одно действие».
- **Уровень сложности — три ступени**: 🟢 Базовый · 🟡 Средний · 🔴 Сложный. Тонкие параметры (диапазон, пропуск в любом месте) спрятаны в «Настроить», для тех, кому нужно.
- **Генератор = движок**, один на много тем. Движок «Арифметика» обслуживает десятки тем 1–4 класса через разные пресеты. Это вместо 180 отдельных страниц.

## Движки (MVP — 8 штук)

| движок | что генерирует | закрывает темы |
| --- | --- | --- |
| Арифметика | примеры, окошки, сравнение, цепочки, столбик, порядок действий | почти вся математика 1–4 |
| Уравнения и задачи | уравнения, текстовые задачи по шаблонам с подстановкой чисел | математика 2–5 |
| Вставь букву | слово с пропуском + проверочное слово из банка | орфография 1–4 |
| Разбор | состав слова, части речи, падежи — выбор/разметка | русский 2–5 |
| Тест | вопросы с вариантами (свои или из банка темы) | любые предметы |
| Слова в сетке | кроссворд, филворд, анаграммы из списка слов темы | словарные слова, английский, окружающий мир |
| Соотнеси / Карточки | пары «слово — перевод», «термин — определение», мемори | английский, окружающий мир |
| Порядок | расставь по порядку: этапы, события, слова в предложении | чтение, история, английский |

Каждый движок: `generate(параметры, seed) → задания с ответами`. Один и тот же seed даёт одинаковый вариант на бумаге и на экране, поэтому можно напечатать лист и проверить его по той же ссылке. Можно и выдать «вариант 1 / вариант 2» двум ученикам.

## Основные сценарии

### 1. Добавить ученика (один раз, 20 секунд)
Имя → класс → предметы (галочки). Всё. Программа по каждому предмету подключается автоматически. Можно отметить «Сейчас проходим: …», чтобы сервис сразу подсвечивал текущую тему.

### 2. Задание за 3 клика (основной сценарий)
```
Ученик (Маша, 3 кл) → Тема (подсвечена «сейчас проходите») → Задание (уровень 🟡) → [Печать] или [Ссылка]
```
Превью листа сразу справа. Кнопка «Другой вариант» перегенерирует. Это число кликов надо держать: у А4Умки 3–5 кликов, но без привязки к ученику.

### 3. Собрать занятие (аналог «Листа дня», но умнее)
Выбрал ученика и длительность (30 / 45 / 60 мин), остальное сервис собирает сам:
```
Разминка (повтор слабой темы) → Новая тема ×2 задания → Закрепление → Домашка
```
Каждый блок можно заменить или удалить. На выходе один PDF и/или одна ссылка на весь набор.

### 4. Домашка по ссылке (то, чего у А4Умки нет)
Ученик открывает ссылку или вводит короткий код (`MASHA-4821`) без регистрации. Решает на экране: те же игровые механики — очки, серия, «Молодец!». **Результат уходит репетитору**: сколько верно, сколько времени, в каких заданиях ошибки.

### 5. Карта прогресса ученика
По каждому предмету дерево тем со светофором:
🟢 освоено (≥ 85 %) · 🟡 в работе · 🔴 западает · ⚪ не начинали.
Кнопка «Задание на ошибки» генерирует новый лист именно по тем типам, где были ошибки.

### 6. Свой контент
Тест, кроссворд и карточки «из своих слов», как у А4Умки, но **с привязкой к теме**. Набор сохраняется в библиотеке репетитора, а не только в браузере, и становится доступным для всех учеников этого класса.

### 7. Отчёт родителю
Одной кнопкой: что прошли за неделю или месяц, процент по темам, что западает. В виде ссылки или PDF. Это то, за что репетитору платят.

## Чем лучше оригинала

| у А4Умки | у нас |
| --- | --- |
| каталог из 180 генераторов по навыкам | программа: предмет → класс → тема |
| класс упоминается только в заголовке | класс — фильтр, у ученика он задан один раз |
| сложность — набор сырых параметров | 3 уровня + «настроить» для продвинутых |
| нет учеников и истории | ученики, история, карта тем |
| результат онлайн-игры видит только ребёнок | результат уходит репетитору |
| «Мои наборы» живут в одном браузере | библиотека в аккаунте, на всех устройствах |
| Лист дня по возрасту и акценту | занятие по программе и слабым местам ученика |
| для дошкольников | 1–4 класс на старте, потом 5–9 |

## Экраны MVP

1. **Ученики** — карточки: имя, класс, предметы, последняя активность, ⚠ если не сдал домашку.
2. **Ученик** — вкладки предметов → дерево тем со светофором, кнопки «Задание» и «Собрать занятие».
3. **Тема** — список готовых заданий по уровням с превью, кнопки Печать / Ссылка / Другой вариант.
4. **Конструктор занятия** — блоки, замена, длительность.
5. **Решение (для ученика)** — игровой экран, крупно, работает с телефона.
6. **Результаты** — лента сданных работ, разбор ошибок.
7. **Библиотека** — свои тесты и наборы слов.

## Модель данных

```
Tutor        id, имя, email
Student      id, tutor_id, имя, класс, предметы[], код_доступа, родитель_контакт
Subject      id, название
Topic        id, subject_id, класс, раздел, порядок, название
Preset       id, topic_id, движок, уровень (1–3), параметры (json), название
Assignment   id, tutor_id, student_id, состав [preset_id + seed], режим (печать/онлайн), срок
Attempt      id, assignment_id, ответы (json), верно, всего, время, ошибки_по_типам
Mastery      student_id, topic_id, процент, обновлено
ContentSet   id, tutor_id, topic_id?, тип (тест/слова), данные (json)
```

## План

1. **MVP (M, ~3–4 недели)**: математика + русский, 1–4 класс, движки «Арифметика», «Вставь букву», «Тест», «Слова в сетке». Ученики, задание за 3 клика, печать и ссылка, результаты.
2. **v2**: собрать занятие, карта прогресса, задание на ошибки, отчёт родителю.
3. **v3**: английский, окружающий мир, 5–9 класс, банк контента от сообщества репетиторов.

Самое трудное — не код, а **контент**: дерево тем по программе и проверенные банки слов и задач под каждую тему. Его стоит начинать собирать параллельно с разработкой.
