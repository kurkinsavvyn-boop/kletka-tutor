# Recon: А4Умка (a4umka.ru) → сервис для репетитора

Дата разбора: 2026-10-26. Платформа: веб (десктоп + мобильный браузер).
Срез: генераторы заданий (печать A4 + онлайн-режим) и сборка набора заданий.
Для кого: частные репетиторы 1–9 классов (старт — начальная школа).

## Источники

## Как сервис устроен (суть)

1. **Один генератор = одна страница.** Форма с параметрами → кнопка «Сделать лист» → новая случайная страница A4 (+ лист ответов). Каждое нажатие — новый вариант.
2. **Две версии каждого генератора.** `/Имя/` — печать, `/Имя/online.html` — то же задание как игра на экране с мгновенной проверкой. Переключатель «Для печати / Решать онлайн» сверху.
3. **Параметры — это и есть сложность.** У «Математики»: тип листа (5), предел счёта (до 5…1000 или свой диапазон), операции, «пропуск в любом месте», счёт картинками, лист ответов. Внутри листа сложность нарастает от простого к сложному.
4. **Свой контент.** Тест, кроссворд, филворд, ребус «из своих слов»: учитель вводит слова и вопросы, генератор их только раскладывает. Есть готовые темы-заготовки и «Мои наборы» (хранятся в браузере).
5. **Шеринг без сервера.** Ссылка «отдать ребёнку» несёт данные внутри URL после `#`. На сервере ничего не хранится.
6. **Нет аккаунтов вообще.** Нет учеников, нет истории, результаты никуда не отправляются. Тест прямо пишет, что не собирает работы и не отправляет результаты учителю.
7. **Навигация по навыкам, а не по программе.** Разделы: Чтение, Рука и моторика, Логика и внимание, Математика, Окружающий мир, Английский, Родителям. Класс упоминается только в заголовке страницы (SEO), как фильтр его нет.
8. **«Лист дня»** — единственный «конструктор занятия»: возраст → время (15/25/35 мин = 3/5/7 заданий) → читает ли → акцент → тема → лист ответов → галочки по заданиям → готовый набор на печать.
9. **Онлайн-игра.** Экран: счётчики (очки, серия, таймер), полоса прогресса, пример крупно, цифровая клавиатура, «Готово». Режимы: на время (60 сек) или 10 примеров, ответ «набрать» или «выбрать из 4». Фидбэк: «Молодец! +10». Финал: «Играть ещё / Сменить уровень».

## Потоки

```
F01 Родитель печатает лист
    S01 → S03 (выбор параметров) → «Сделать лист» → S04 → печать
    кликов на счастливом пути: 3–5

F02 Ребёнок играет онлайн
    S02 → S05 (уровень, операция, режим) → S06 → S07
    кликов до первого примера: 2

F03 Учитель делает тест/кроссворд и отдаёт ссылкой
    S08 (ввод слов) → «Собрать» → «Ссылка» → ребёнок открывает S09
    edge: слова не пересекаются, нет правильного ответа, слишком длинный вопрос
    провал: результат ребёнка учитель не видит

F04 Набор на день
    S10: возраст → время → акцент → тема → печать
    кликов: 1 (дефолт) … 6
```

## Компоненты

- **Сегмент-кнопки** (выбор одного из N) — онлайн-настройка, Лист дня. Удобнее радиокнопок.
- **Радиогруппа в рамке с легендой** — печатные генераторы.
- **Чекбокс-опция** с пояснением после тире («Пропуск в любом месте — 2 + □ = 5 (сложнее!)»).
- **Блок вопроса** (текст + 2–4 ответа + отметка правильного + «+ Ответ / − Последний / Удалить»).
- **Textarea «слово — вопрос»** с живым счётчиком принятых пар.
- **Цифровая клавиатура** 3×4.
- **Счётчики** (очки / серия / таймер) + прогресс-бар.
- **Превью A4** под формой.
- **Шапка листа**: Дата / уровень / Время.

## Модель данных (выведенная)

Сервер почти ничего не хранит. Всё живёт в браузере:

```
GeneratorConfig  тип листа, предел/диапазон, операции, флаги (ответы, картинки, ч/б)
                 evidence: S03 форма; confidence: high
Item             условие, правильный ответ, (варианты)  — генерируется на лету
                 evidence: S04, S06; confidence: high
WordSet          [слово, вопрос], название — «Мои наборы», localStorage
                 evidence: S08; confidence: medium (хранилище — догадка по «на сервере не сохраняется»)
SharedTask       данные задания в URL-фрагменте #
                 evidence: текст на S08; confidence: high
```

Нет: пользователя, ученика, результата, истории, программы/классов.

## Что не переносим

- Иллюстрации, маскот, тексты страниц, банки слов и картинок, сценарии интерактивных уроков с озвучкой — это их контент. Делаем свои банки.
- Бренд, название, палитру.
- Рекламу и SEO-простыни.

## Размер

~180 генераторов у оригинала — копировать их по одному незачем. Большинство — вариации ~15 «движков» (арифметика, вставь букву, соотнеси, тест, кроссворд/филворд, последовательность…). MVP на 3 предмета × 1–4 класс × 8 движков — **M (несколько недель)**. Полный охват 1–9 класса с банками заданий — **L (квартал)**.

Трудные места:
1. **Контент**: дерево тем по программе (ФГОС) и банки слов/задач под каждую тему.
2. **Качество генераторов** для языковых предметов: нужны проверенные банки, а не случайность.
3. **Результаты без регистрации ученика**: вход по коду/ссылке, но с привязкой к ученику у репетитора.
