# Клетка — генератор заданий для репетитора

Кликабельный прототип сервиса, в котором репетитор ведёт учеников по программе
и за пару кликов выдаёт задания: на печать (лист A4 с ключом) или домашкой по ссылке
с результатом обратно репетитору.

**Открыть прототип:** https://kurkinsavvyn-boop.github.io/kletka-tutor/

Один файл `index.html`, без сборки и зависимостей. Его можно открыть и локально в браузере.

## Что умеет

- **Ученики.** Класс в школе, предметы, удаление ученика вместе с его работами.
- **Маршрут по предмету.** Плитки «пройдено / сейчас / дальше / потом», кнопки
  «Задание по текущей теме», «Тема пройдена, дальше», «Повторить пройденное».
  Текущая тема у каждого предмета своя. Можно начать с темы старше класса ученика.
- **Математика 1–4 класса.** 29 тем в едином порядке, у каждой 3 уровня сложности.
- **Генератор «Арифметика».** Примеры, окошки, сравнение, столбик, порядок действий,
  уравнения с x. Учитывает переход через десяток, деление только нацело,
  сложность нарастает к концу листа. Один номер варианта даёт одинаковые задания
  на бумаге и на экране.
- **Виды листа.** Тренировка (одна тема), Урок (разминка, тема, задачи, бонус),
  Проверочная, Домашка и Свой лист из блоков: любые темы, уровни и количество.
- **Текстовые задачи.** Проверенные шаблоны по программе 1–4 класса: было/стало,
  больше/меньше на, в несколько раз, цена и стоимость, движение. Подставляются только
  числа, имена и предметы, падежи считаются автоматически.
- **Величины и фигуры на клетках.** Единицы длины, времени и массы; периметр и площадь.
- **Свои темы.** Из генератора (вид задания, действия, диапазон) или списком
  «вопрос = ответ», в том числе по русскому: `м□локо = о`.
- **Повторение.** Лист из 3 пройденных тем, сначала самые слабые. Результат
  записывается в каждую исходную тему.
- **Экран ученика.** Цифровая клавиатура или ввод словом, очки, серия, разбор ошибок.

## Ограничения прототипа

- Данные хранятся в `localStorage` браузера, сервера нет.
- Ссылка для ученика настоящая: задание целиком лежит в самой ссылке. Результат сам
  не приходит: ученик получает код результата, репетитор вносит его в карточке ученика.
- PDF не скачивается. На экране печати лист разложен по страницам A4, задание и ключ отдельно.
- Для русского нет встроенного генератора, только свои темы списком.
- Дерево тем математики составлено по типовой программе начальной школы
  и не сверено с ФГОС или конкретным учебником.
